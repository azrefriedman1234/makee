# טלגרם לייב – עברית, בלי שרת (כולל הגדרות בתוך האפליקציה)

מה יש:
- התחברות לטלגרם (TDLib) – נשמר מקומית על המכשיר
- הודעות בלייב
- תרגום אוטומטי לעברית (LibreTranslate, חינמי – ניתן לשנות URL)
- Thumbnail למדיה + סימון מלבני טשטוש במגע
- עיבוד טשטוש מקומי עם FFmpegKit (תמונה/וידאו)
- שליחה לערוץ ציבורי שאתה מגדיר (@...)

## שימוש
1. התקן APK
2. במסך הגדרות הכנס API_ID + API_HASH
3. התחבר לטלגרם
4. בחר יעד ערוץ לשליחה ושמור
5. בחר הודעה, הורד Thumbnail, סמן מלבנים, הורד מדיה, החל טשטוש, שלח לערוץ

## בנייה אונליין
GitHub Actions -> Build APK -> Artifacts -> app-debug-apk
